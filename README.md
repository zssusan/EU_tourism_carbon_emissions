# EU_tourism_carbon_emissions
Directed valued exponential random graph models for bilateral tourism-transport CO₂ among the 27 EU countries in 2012, 2016, 2019 and 2024. Each year is estimated separately by maximum pseudolikelihood.

Files
File	Contents
data	Estimation sample, CSV, 2,808 rows (702 directed international edges × 4 years)
valued_ergm_code.py	Reads data and estimates the model
result	Coefficients, standard errors, z statistics and p-values, written by the script
